# Currency Converter 💱

A responsive currency converter built with **React**, **Vite**, and **Tailwind CSS** that allows users to convert amounts between different currencies using exchange rates fetched from an API.

## 🌐 Live Demo

**[View Currency Converter](https://currency-converter-gold-two.vercel.app/)**

## ✨ Features

- **Currency Conversion** — Convert amounts between different currencies.
- **Multiple Currencies** — Select currencies using dropdown menus.
- **Swap Currencies** — Quickly switch the source and target currencies.
- **Dynamic Conversion** — Update the converted amount based on the selected currencies and entered value.
- **Responsive Design** — A clean interface for different screen sizes.
- **Finance-Themed Background** — A background image for an enhanced visual experience.

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Currency Exchange API
- Vercel
